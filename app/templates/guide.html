GUIDEBOOK

화면 그대로 따라 하면
첫 카드뉴스가 나옵니다.

API 키 넣는 것부터 배경 이미지 만들기, 엑셀 DB로 남기는 것까지 여섯 단계입니다. 아래 그림은 전부 실제 프로그램 화면입니다.

시작하기 전에 딱 두 가지

  1. Anthropic API 키 — 글(전략·카드 문구)을 씁니다. console.anthropic.com 에서 발급합니다.
  2. OpenAI API 키 — 배경 이미지를 만듭니다. platform.openai.com 에서 발급합니다.

둘 다 있어야 하는 것은 아닙니다. Anthropic 키만 있어도 글은 써집니다. 반대로 Anthropic 키가 없으면 OpenAI 로 글을 씁니다. 이미지는 OpenAI 키가 있을 때만 자동 생성되고, 없으면 직접 올리면 됩니다.

1 키 넣기 2 주제 → 전략 3 카드 구성 4 배경 이미지 5 글자 편집 6 저장 · DB

STEP 1

내 API 키를 넣습니다

맨 오른쪽 설정 탭을 엽니다. 키는 이 브라우저에만 저장되고 어디로도 보내지 않습니다.

여기서 자주 막힙니다
  • 키만 붙여넣으세요. 앞뒤에 설명이나 따옴표가 딸려 오면 실패합니다.
  • 키를 새로 넣었다면 설정 저장을 먼저 누르고 테스트하세요. 테스트는 저장된 키로 합니다.
  • 이미지 모델을 쓸 수 없다고 나오면 OpenAI 계정의 결제 수단·인증을 확인하세요.

STEP 2

주제를 넣고 전략을 고릅니다

한 줄이면 됩니다. 프로그램이 주제를 좁히고, 서로 다른 각도의 앵글 3안을 만들어 줍니다.

STEP 3

카드를 구성합니다

고른 앵글로 카드 다섯 장과 캡션·해시태그까지 한 번에 만듭니다. 만들어지면 바로 편집 화면으로 넘어갑니다.

STEP 4

카드 글에 맞는 배경을 만듭니다

오른쪽 이미지 탭입니다. 그 카드에 적힌 글을 읽고 어울리는 장면을 그립니다. 아무 그림이나 넣는 것이 아닙니다.

알아두면 좋습니다
  • 이미지는 카드마다 따로 만듭니다. 한 장씩 확인하며 만드는 편이 낫습니다.
  • 직접 찍은 사진이 있으면 아래 칸에 끌어놓으면 됩니다. 이때는 비용이 들지 않습니다.
  • OpenAI 키가 없다면 프롬프트 복사로 문구만 받아 다른 곳에서 만들어 올려도 됩니다.

STEP 5

글자를 다듬습니다

카드 위의 글자는 하나하나 옮기고 고칠 수 있습니다. 끌어서 위치를 바꾸고, 더블클릭해서 바로 고칩니다.

STEP 6

저장하면 DB에 남습니다

저장 · DB 기록을 누르면 작업물과 함께 제작 데이터가 쌓입니다. 날짜 · 주제 · 컨셉축 · 글포맷 · 카드별 문구까지 기록됩니다.

가져갈 수 있는 것 세 가지

PNG 내보내기
카드 한 장씩 1080×1350 으로 그립니다.
ZIP 받기
카드 PNG 전부 + 캡션·해시태그 텍스트를 한 묶음으로 받습니다.
엑셀 DB 내려받기
지금까지 만든 것이 두 시트(카드뉴스 · 카드)로 정리됩니다.

웹에서 쓸 때 저장 위치는 이 브라우저 안입니다. 다른 기기에서 이어서 보려면 ZIP · 엑셀로 받아 두세요.

비용

사용료는 각자 본인 계정으로 나갑니다

중간에 거쳐 가는 서버가 없습니다. 생성 요청은 내 브라우저에서 각 회사 서버로 바로 갑니다.

내 브라우저 → Anthropic · OpenAI
  • 키는 내 브라우저에만 저장됩니다. 만든 사람도 볼 수 없습니다.
  • 요금은 내가 넣은 키의 계정에 청구됩니다. 같은 주소로 접속한 다른 사람은 자기 키를 따로 넣습니다.
  • 글쓰기는 몇 원 단위, 이미지가 대부분을 차지합니다. 이미지는 카드마다 따로 만드니 필요한 것만 만드세요.
  • 직접 올린 사진을 배경으로 쓰면 이미지 비용은 들지 않습니다.

이제 만들어 볼 차례입니다.
