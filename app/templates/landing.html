실제 편집 화면과 이 프로그램으로 만든 완성 카드입니다. 배경은 AI 생성 이미지입니다.

PROBLEM

카드뉴스는 만들었는데,
제작 데이터는 어디에 남아 있나요?

1

구성이 막힙니다

주제는 있지만 첫 장의 훅부터 마지막 CTA까지 연결하기 어렵습니다.

2

작업이 흩어집니다

문구, 이미지, 캡션, 완성 파일이 서로 다른 창과 폴더에 남습니다.

3

기록이 사라집니다

어떤 주제·전략·문구로 만들었는지 남지 않아 다음 작업에서 다시 처음부터 시작합니다.

카드뉴스 스튜디오는 이 과정을 하나의 제작 흐름으로 연결합니다.

EDITOR

보이는 그대로 고치고,
같은 모습으로 내보냅니다.

1080×1350 캔버스에서 텍스트 레이어를 드래그하고 더블클릭해 수정합니다. 편집 화면과 PNG 렌더가 같은 카드 스크립트와 스타일을 사용해 화면과 결과물의 차이를 줄였습니다.

  • 좁힌 주제와 타깃 — 입력한 주제를 더 좁히고 대상을 정리합니다.
  • 핵심·검색 키워드 — 본문에 쓸 말과 검색용 말을 나눠 보여줍니다.
  • 앵글 3안 — 컨셉 축이 서로 다른 후보를 나란히 비교합니다.
  • 선택 근거 — 각 앵글에 후킹·퍼널 단계·CTA 키워드가 함께 붙습니다.
  • 카드 순서와 썸네일 — 왼쪽 목록에서 장을 옮겨 다닙니다.
  • 드래그·더블클릭 — 위치를 끌어 옮기고 그 자리에서 문구를 고칩니다.
  • 레이어 조정 — 위치·크기·굵기·행간·정렬·색을 다룹니다.
  • 카드 문구 재작성 — 한 장만 다시 쓰도록 요청할 수 있습니다.
  • 장면 다시 잡기 — 지금 카드에 적힌 글에 맞춰 장면을 다시 설계합니다.
  • 자동 생성 또는 업로드 — OpenAI로 만들거나 직접 만든 이미지를 넣습니다.
  • 프롬프트 복사 — OpenAI 키 없이 외부 도구를 쓸 수 있습니다.
  • 초점·어둡기 — 글자가 잘 읽히도록 배경을 맞춥니다.
  • 발행 문구 — 캡션·댓글 CTA·다음 편 예고·해시태그·상태를 정리합니다.
  • PNG 내보내기 — 화면과 같은 1080×1350 파일로 저장합니다.
  • ZIP 받기 — PNG와 caption.txt를 한 번에 내려받습니다.
  • 보관함과 DB — 지난 편을 다시 열고 엑셀 기록을 내려받습니다.

SETUP

내 PC에서 실행하고,
내 키로 연결합니다.

프로그램은 로컬 서버에서 실행됩니다. 텍스트 생성에는 Anthropic API 키가 필요합니다. 배경 이미지는 OpenAI API로 자동 생성하거나, 프롬프트를 복사해 외부에서 만든 이미지를 직접 넣을 수 있습니다.

1. 실행

run.bat 더블클릭으로 최초 환경 설치와 앱 실행이 진행됩니다.

2. 키 입력

사용자가 입력한 키는 기본적으로 해당 브라우저에 저장되고, 요청할 때만 전달됩니다.

3. 이미지 선택

수동 모드에서는 OpenAI 키 없이 프롬프트 복사와 이미지 업로드를 사용할 수 있습니다.

4. 비용

이미지 생성 등 외부 API 사용 비용은 각 제공사 정책에 따라 발생합니다.

WHY IT HOLDS UP

완성본만 저장하지 않고,
제작 과정까지 기록합니다.

내장 전략 플레이북컨셉 축·글 포맷·구매 구조·CTA 기준을 생성 기준으로 사용합니다.
원문 범위 제약원문 모드에서는 원문에 없는 사실을 만들지 않도록 프롬프트로 제한합니다.
민감 주제 고지건강·행동 관련 내용에는 상담 고지 기준을 적용합니다.
발행 전 자가진단첫 장 후킹·가독성·주제 적합성·저장 이유를 점검 항목으로 제공합니다.
로컬 기록 보관프로젝트와 카드 단위 기록을 로컬 파일과 엑셀에 남깁니다.
화면과 출력 일치편집 화면과 PNG 출력이 같은 카드 렌더 자산을 공유합니다.

위 항목은 제작을 돕는 장치입니다. AI 출력의 사실성이나 법적·의학적 정확성을 보증하지 않습니다. 수치·효능·전문 정보와 최종 문구는 게시 전에 사용자가 직접 확인해야 합니다.

HOW IT WORKS

한 줄의 주제가 결과물이 되기까지

입력에서 저장까지 다섯 단계입니다.

1

주제 또는 원문 넣기

주제 한 줄로 시작하거나 .md·.txt와 붙여넣은 글을 요약해 주제 후보를 고릅니다.

2

키워드와 전략 고르기

핵심·검색 키워드와 서로 다른 앵글 3개를 확인하고 하나를 선택합니다.

3

카드 구성 만들기

3~10장의 역할, 문구, 캡션, 해시태그와 이미지 프롬프트 초안을 만듭니다.

4

캔버스에서 다듬기

텍스트를 끌어 옮기고 바로 수정하며, 배경 이미지와 초점·어둡기를 조정합니다.

5

내보내고 DB에 쌓기

1080×1350 PNG와 ZIP을 받고, 주제·전략·카드 문구·캡션·상태를 엑셀 DB에 남깁니다.
