# 카드뉴스 스튜디오

주제만 넣으면 **옵시디언의 마케팅 자료를 근거로** 카드뉴스 전략·문구·이미지를 만들고,
프로그램 안에서 편집한 뒤 PNG와 엑셀 DB로 남기는 프로그램입니다.

**두 가지 방식으로 씁니다.**

| | 로컬앱 | 웹앱 |
|---|---|---|
| 실행 | `run.bat` (FastAPI + Playwright) | 브라우저에서 [/app/](https://cardnews-studio-seven.vercel.app/app/) 열기 |
| 설치 | 필요 | 없음 |
| 저장 | `data/` 폴더의 JSON·PNG·엑셀 | 브라우저 IndexedDB → ZIP·엑셀로 내려받기 |
| 옵시디언 전략 노트 참조 | 됨 | 안 됨 (내장 지침만 사용) |
| API 사용료 | 내 키 | **쓰는 사람 각자의 키** |

기능은 같습니다. 전략 3안 → 카드 구성 → 배경 이미지 → 레이어 편집 →
PNG·ZIP·엑셀 DB 까지 웹앱에서도 그대로 됩니다.

```
주제 입력  ─┐
            ├→ 키워드·앵글 추출     (Claude)
MD·블로그 ─┘   → 카드 구성 + 캡션    (Claude)
붙여넣기         → 배경 이미지        (OpenAI gpt-image-2 또는 ChatGPT 수동)
 → 요약           → 편집 (드래그·인라인 수정)
                    → PNG 내보내기 + 엑셀 DB 기록
```

## 화면

| 주소 | 용도 |
|---|---|
| `http://127.0.0.1:8765/` | **앱 본체(로컬)** — 카드뉴스를 만들고 편집하는 작업 화면 |
| `http://127.0.0.1:8765/cardnews-studio` | **랜딩페이지** — 제품 소개. 처음 보는 사람에게 보여줄 화면 |
| `배포주소/app/` | **웹앱** — 같은 화면이 서버 없이 브라우저에서 돕니다 |

랜딩페이지의 `카드뉴스 만들기` 버튼은 웹앱(`/app/`)으로 연결됩니다.
스크린샷과 완성 카드는 이 프로그램에서 실제로 캡처·생성한 것입니다.
화면을 다시 캡처하려면 `tools/` 의 스크립트를 참고하세요.

## 처음 실행

`run.bat` 을 더블클릭하면 가상환경 생성 → 패키지 설치 → Chromium 설치까지 자동으로 하고
브라우저에서 <http://127.0.0.1:8765> 를 엽니다. 두 번째부터는 바로 서버만 뜹니다.

수동으로 하려면:

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8765
```

### API 키 등록

**API 키는 쓰는 사람마다 각자 넣습니다.** 설정 탭에서 입력하면 **그 사람의 브라우저에만**
저장되고, 요청할 때만 헤더로 서버에 전달됩니다. 서버에는 저장되지 않습니다.
같은 주소로 다른 사람이 접속하면 그 사람은 자기 키를 따로 넣어야 합니다.

| 키 | 어디서 받나 | 용도 | 없으면 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | <https://console.anthropic.com> → API Keys | 원문 요약 · 키워드 추출 · 카드 구성 · 카드 재작성 | **필수** |
| `OPENAI_API_KEY` | <https://platform.openai.com/api-keys> | 배경 이미지 자동 생성 | 프롬프트만 복사해 ChatGPT에서 만들어 넣으면 됨 |

**입력 순서**

1. 키를 붙여넣고 **설정 저장** — 입력칸이 비워지고 라벨이 `내 키 …7777 사용 중` 으로 바뀝니다
2. **연결 테스트** 버튼으로 확인 — 성공하면 사용 중인 모델 이름이 나옵니다

키를 비워두고 저장하면 **기존 키가 그대로 유지**됩니다(실수로 지워지지 않습니다).

### 키가 어디서 오는지

설정 탭의 키 이름 옆에 지금 무슨 키가 쓰이는지 뒤 4자리와 함께 표시됩니다.
우선순위는 위에서부터입니다.

| 표시 | 뜻 |
|---|---|
| `내 키 …7777 사용 중 (이 브라우저)` | 내가 입력한 개인 키. 항상 최우선 |
| `이 PC 공용 키 …abcd 사용 중` | 이 PC `.env` 의 키. 아무도 자기 키를 안 넣었을 때만 |
| `OS 환경변수 …abcd 사용 중` | PC 환경변수. 위 둘이 없을 때만 |
| `없음 — 본인 키를 입력하세요` | 아무 키도 없음 |

### 여러 명이 쓰거나 프로그램을 나눠줄 때

설정 탭의 두 체크박스로 정합니다.

| 체크박스 | 켜면 |
|---|---|
| **각자 키 입력 필수** | 이 PC의 공용 키를 무시합니다. **모든 사람이 자기 키를 넣어야만** 동작합니다 |
| **이 PC에도 저장** | 내 키를 `.env` 에 저장합니다. 이 PC를 쓰는 모두가 내 키를 쓰게 되니 **혼자 쓰는 PC에서만** 켜세요 |

프로그램을 남에게 줄 때는 `.env` 를 빼고 주면 됩니다(`.gitignore` 에 이미 들어 있습니다).
받는 사람은 자기 키를 넣어야 쓸 수 있습니다.

`이 브라우저에서 내 키 지우기` 로 언제든 내 키를 지울 수 있습니다.

연결 테스트가 알려주는 것:

| 메시지 | 뜻 |
|---|---|
| `API 키가 올바르지 않습니다` | 키를 잘못 붙여넣었거나 폐기된 키 |
| `이 키로는 접근할 수 없습니다` | 워크스페이스·조직 권한 문제 |
| `'…' 모델을 찾을 수 없습니다` | 모델 이름 오타 (기본값 `claude-opus-5`) |
| `키는 정상이지만 gpt-image-2 을 쓸 수 없습니다` | OpenAI 계정 본인 인증이 필요 |

이미지 생성 방식을 **프롬프트만 (수동)** 으로 두면 OpenAI 키 없이 쓸 수 있고,
자동 생성 버튼을 눌러도 실수로 과금되지 않습니다.

## 배포 (Vercel)

**FastAPI 서버는 Vercel에 올릴 수 없습니다.** PNG 내보내기에 Playwright + Chromium(300MB+)이
필요해 서버리스 용량 한도를 넘고, 프로젝트 JSON·이미지·엑셀 DB를 디스크에 쓰는데
Vercel 파일시스템은 읽기 전용이라 저장한 작업물이 사라집니다.

그래서 **서버를 없앴습니다.** `app/static/webapi.js` 가 브라우저 안에서 서버 몫을 합니다.

| 서버가 하던 일 | 브라우저에서 |
|---|---|
| Claude·OpenAI 호출 | 브라우저 → 각 회사 서버로 **직접** (키는 이 브라우저에만) |
| 프로젝트 저장 | IndexedDB |
| PNG 렌더 (Playwright) | `<canvas>` 로 직접 그림 |
| ZIP 묶기 | 무압축 ZIP 을 직접 조립 |
| 엑셀 DB | 최소 xlsx(= XML 이 든 ZIP)를 직접 조립 |

덕분에 **배포한 사람에게는 서버 비용도 API 비용도 들지 않습니다.**
생성 요청은 각 사용자의 브라우저에서 나가고, 사용료는 그 사람 계정에 청구됩니다.

```bash
python tools/build_site.py      # site/ 에 랜딩 (site/ 를 통째로 지우고 다시 만든다)
python tools/build_webapp.py    # site/app/ 에 웹앱 — 반드시 이 순서로
python tools/check_site.py      # 배포 전 검사
```

> 순서가 중요합니다. `build_site.py` 가 `site/` 를 지우므로 웹앱을 먼저 만들면 날아갑니다.

웹앱은 `/app/` 에 놓이는 것을 전제로 뿌리 기준 절대 경로를 씁니다
(`tools/build_webapp.py` 의 `BASE`). `vercel.json` 이 `trailingSlash: false` 라
`/app/` 이 `/app` 으로 되돌려지는데, 상대 경로였다면 이때 자산이 전부 404 납니다.

배포 주소는 `tools/build_site.py` 의 `DEFAULT_BASE_URL` 에 고정돼 있습니다.
OG 이미지와 canonical 이 절대 URL 이어야 링크 미리보기가 나오기 때문입니다.
**커스텀 도메인을 붙이면 이 값만 바꾸면 됩니다.**

`vercel.json` 이 `site/` 를 배포 폴더로 지정합니다. Vercel에서 이 저장소를 연결하면
빌드 명령 없이 그대로 서비스됩니다.

### 빌드 자동화 (GitHub Actions)

랜딩이나 앱 소스를 고쳐서 push 하면 `.github/workflows/build-site.yml` 이
`site/` 와 `site/app/` 을 다시 만들고, 검사를 통과하면 커밋합니다.
**손으로 빌드할 일이 없습니다.**

| 무엇을 고치면 | 자동으로 |
|---|---|
| `app/templates/landing.html` | `site/` 재빌드 → 검사 → 커밋 → Vercel 배포 |
| `app/static/landing/**` (스타일·화면·카드) | 〃 |
| `app/templates/index.html`, `app/static/*.js`, `*.css` | 〃 (웹앱도 함께 다시 만듭니다) |
| `knowledge/brand.json` | 〃 |
| `tools/build_site.py`, `tools/build_webapp.py` | 〃 |

- Pull Request 에서는 **검사만** 하고 커밋하지 않습니다.
- 배포 주소는 `build_site.py` 의 `DEFAULT_BASE_URL` 을 씁니다. 다른 주소로 한 번만
  빌드하려면 Actions 탭에서 **Run workflow** 에 주소를 입력하면 됩니다.
- 되돌이 실행은 두 겹으로 막혀 있습니다. 감시 경로에 `site/**` 가 없고,
  `GITHUB_TOKEN` 으로 만든 푸시는 워크플로를 다시 켜지 않습니다.

`tools/check_site.py` 가 배포 전에 다음을 확인하고, 하나라도 걸리면 배포를 막습니다.

없는 자산 · 실물 없는 링크(눌렀을 때 404) · 서버 API 참조 ·
메타 태그 누락 · API 키 문자열 혼입 · CRLF 혼입 · 과도한 용량

| 경로 | 내용 |
|---|---|
| `/` | 랜딩페이지 |
| `/cardnews-studio` | 같은 페이지 (지침서 권장 URL) |
| `/app/` | **웹앱** — 서버 없이 브라우저에서 도는 본체 |

## 전략은 어디서 오나

`knowledge/playbook.md` 가 **헌법**이고, 옵시디언 원문 노트가 **근거**입니다.
Claude를 부를 때마다 이 둘을 시스템 프롬프트에 넣습니다.

| 파일 / 폴더 | 내용 | 저장소 |
|---|---|---|
| `knowledge/playbook.md` | 카드뉴스 전략 기준 (컨셉 축 · 글 포맷 · 판매 구조 · CTA · 자가진단) | 제외 |
| `knowledge/brand.json` | 브랜드 킷 (색상 4테마 · 타깃 · 톤 · 이미지 스타일 · 안전 고지) | 포함 |
| 참조 노트 폴더 (읽기 전용) | 설정 탭에서 각자 지정 | — |

`playbook.md` 는 유료로 구입한 자료를 정리한 파일이라 저장소에 올리지 않습니다.
직접 만드는 방법은 [knowledge/README.md](knowledge/README.md) 를 보세요.

참조 노트 폴더를 지정하면 주제와 관련도가 높은 章을 골라 발췌해 함께 넣습니다.
**원본 노트는 절대 수정하지 않고 읽기만** 합니다.

전략을 바꾸고 싶으면 원본이 아니라 `knowledge/playbook.md` 를 고치세요.
참조 폴더는 설정 탭에서 추가·변경할 수 있습니다.

## 화면

**1 · 주제** — 입력 방식이 두 가지입니다.

- **주제만 입력** — 주제 한 줄로 바로 시작
- **원문에서 만들기** — MD 파일이나 블로그 글을 붙여넣고 요약해서 시작

원문 모드에서는 `.md` / `.txt` 파일을 열거나 본문을 붙여넣은 뒤 **원문 요약하고 주제 뽑기** 를 누릅니다.
Claude가 요약 · 핵심 포인트 · **원문에 실제로 적힌 사실** · 인용 문장 · **주제 후보 3개** 를 뽑아줍니다.
주제 후보를 누르면 아래 주제 칸에 들어갑니다.

원문을 넣으면 이후 모든 단계에서 **원문에 있는 내용만 사실로 쓰도록** 제약이 걸립니다.
없는 수치나 효능을 지어내지 않고, 인용 문장은 그대로 쓸 수 있습니다.
원문이 6만 자를 넘으면 앞부분만 쓰고 **잘렸다고 알려줍니다**(조용히 버리지 않습니다).

**2 · 키워드 · 전략** — 좁힌 주제 · 타깃 · 고민 · 키워드와 함께
**컨셉 축이 서로 다른 앵글 3개**가 나옵니다. 각 앵글에는 후킹·퍼널 단계·CTA 키워드와
"왜 이 축을 골랐는지"가 붙습니다. 하나를 고르면 카드가 구성됩니다.

**3 · 편집** — 1080×1350 캔버스.

- 텍스트를 **끌어서** 옮기고, **더블클릭**해 그 자리에서 고칩니다
- 오른쪽 인스펙터 4탭
  - **레이어** — 위치·크기·굵기·행간·정렬·색
  - **카드** — 배지/타이틀/서브/본문/노트/팁, `이 카드 다시 쓰기`(Claude)
  - **이미지** — 장면 다시 잡기 · 생성 · 프롬프트 복사 · 끌어놓기 · 초점 · 어둡기
  - **발행** — 캡션 · 해시태그 · 댓글 CTA · 다음 편 예고 · 30초 자가진단 결과 · 상태
- `PNG 내보내기` → 화면과 **똑같은** 1080×1350 PNG (Chromium 렌더)
- `ZIP 받기` → PNG + `caption.txt`
- `저장 · DB 기록` → 엑셀 DB 갱신

**보관함** — 지난 편 목록, 열기/삭제, 엑셀 DB 내려받기.

## 저장 구조

```
data/
  cardnews_db.xlsx            엑셀 DB
  projects/<날짜-주제>/
    project.json              편집 상태 전체 (레이어 좌표까지)
    assets/card-01.png        배경 이미지
    cards/card-01.png         내보낸 완성본
```

### 엑셀 DB 시트

| 시트 | 단위 | 주요 열 |
|---|---|---|
| `카드뉴스` | 한 편 | 날짜 · 주제 · 타깃 · **컨셉축 · 글포맷 · 퍼널단계 · 후킹 · CTA키워드** · 캡션 · 해시태그 · 자가진단 · 전략메모 · 참고자료 · **원문제목 · 원문종류 · 원문출처 · 원문요약** · 폴더경로 · 상태 |
| `카드` | 카드 1장 | 카드번호 · 역할 · 템플릿 · 타이틀 · 서브 · 본문 · 이미지프롬프트 |
| `템플릿` | 테마×템플릿 | 사용 횟수 · 최근 사용일 |

같은 프로젝트를 다시 저장하면 행이 쌓이지 않고 **덮어씁니다**.
열 구성이 바뀌면 기존 시트를 `카드뉴스_이전…` 으로 보존하고 새 시트를 만듭니다.

```
  static/           app.js · card.js · style.css · card.css
```

편집 화면과 PNG 내보내기가 **같은 `card.js` / `card.css`** 를 씁니다.
화면에서 본 것이 그대로 나옵니다.

랜딩페이지는 앱과 분리돼 있습니다.

```
app/templates/landing.html      랜딩 마크업
app/static/landing/
  landing.css / landing.js      랜딩 전용 스타일·동작
  shots/                        실제 앱 화면 캡처 (WebP)
  cards/                        실제 완성 카드 (WebP)
  fonts/                        랜딩용 Pretendard 서브셋 (각 ~35KB)
  favicon.svg, og-*.png
tools/subset_fonts.py           문구를 크게 바꿨을 때 폰트 서브셋 재생성
```

원본 Pretendard OTF는 3MB라 첫 화면에 부담이 커서, 랜딩에는 쓰이는 글자만 남긴
WOFF2 서브셋(합계 71KB)을 씁니다. 앱의 카드 렌더는 계속 원본 OTF를 씁니다.

## 배경 이미지

기본 모델은 **gpt-image-2**, 크기는 1024×1536입니다(설정에서 변경 가능).
설정 탭의 `이 키로 쓸 수 있는 이미지 모델 보기` 로 실제 사용 가능한 모델을 확인할 수 있습니다.
모델이 그 크기를 지원하지 않으면 자동으로 `auto` 로 한 번 더 시도합니다.

프롬프트는 **카드에 실제로 적힌 글을 읽고** 만듭니다. 세 가지가 자동으로 들어갑니다.

| 항목 | 내용 |
|---|---|
| 카드 문구 | 타이틀·서브·본문·노트를 그대로 넣고 "이 문장이 묘사하는 상황을 그려라" 라고 지시 |
| 역할별 무드 | 후킹은 멈칫하게, 문제제기는 공감되게, 상품연결은 질감 위주 등 |
| 템플릿별 여백 | 글자가 올라갈 자리를 비워둠 (커버는 상단 45%, 본문형은 위·아래 1/3) |

브랜드 스타일 지시는 영문(`image_style_en` / `image_avoid_en`)으로 넣습니다 — 이미지 모델이 영어를 훨씬 잘 따릅니다.

**이 카드 글에 맞는 장면 다시 잡기** 를 누르면 Claude가 지금 화면의 문구를 읽고
배경 장면 자체를 다시 씁니다. 문구를 고친 뒤에 누르면 이미지가 새 문구를 따라갑니다.
어떤 장면을 왜 골랐는지 한국어로 함께 보여줍니다.

## 카드에 들어가는 글자

카드에는 **레이어에 있는 글자만** 찍힙니다.
페이지 번호(`01 / 07`), 영문 브랜드명(`MYOHAN CUSHION`), 한글 브랜드명(`묘한쿠션`)은 넣지 않습니다.
모든 글자는 끌어 옮기고 고치고 지울 수 있습니다.

## 알아둘 것

- 폰트는 기존 카드뉴스와 같은 **Pretendard**(없으면 Noto Sans KR → 맑은 고딕)를 씁니다.
- 이미지 생성 비용은 장당 약 $0.02~0.19 입니다. 아끼려면 `프롬프트 복사` → ChatGPT → 끌어놓기.
- 키·모델 설정은 저장 즉시 반영됩니다. **코드를 고쳤을 때만** 앱을 다시 시작하세요.
- 카드 텍스트는 플레이북 하드룰(타이틀 12자·본문 22자 내외)에 맞춰 생성되지만,
  줄이 넘치면 인스펙터에서 크기나 폭을 줄이면 됩니다.
- 건강·행동 주제는 마지막 카드에 수의사 상담 고지가 들어갑니다.
