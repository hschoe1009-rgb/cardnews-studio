# knowledge/

카드뉴스를 구성할 때 Claude가 따르는 기준이 들어가는 폴더입니다.

| 파일 | 내용 | 저장소 포함 |
|---|---|---|
| `brand.json` | 브랜드 톤·색상 테마·타깃·이미지 스타일 | 포함 |
| `playbook.md` | 카드뉴스 전략 플레이북 (컨셉 축·글 포맷·CTA·자가진단) | **제외** |

## playbook.md 가 없는 이유

이 파일은 유료로 구입한 자료를 정리한 것이라 공개 저장소에 올리지 않습니다.
(`.gitignore` 에 등록돼 있습니다.)

없어도 프로그램은 동작하며, 이때는 `brand.json` 과 설정에서 지정한
노트 폴더만 근거로 사용합니다. 다만 전략 품질은 떨어집니다.

## 직접 만들려면

`playbook.md` 에 아래 내용을 마크다운으로 적으면 됩니다.

- 컨셉을 정하는 기준 (어떤 각도로 주제를 볼 것인가)
- 글의 목적별 유형 (유입용 / 정보용 / 판매용 / 고객수집용)
- 판매성 글의 뼈대 (후킹 → 문제 → 해결 → 상품 + CTA)
- 카드 텍스트 길이 하드룰 (한 줄 몇 자, 몇 줄까지)
- CTA 규칙 (링크를 어디에 둘 것인가)
- 발행 전 자가진단 항목

`app/strategy.py` 가 이 파일을 그대로 시스템 프롬프트에 넣습니다.
