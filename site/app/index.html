API 키는 쓰는 사람이 각자 넣습니다. 서버가 없어 키는 이 브라우저를 벗어나지 않습니다. 생성 요청은 브라우저에서 각 회사 서버로 직접 가고, 사용료는 본인 계정에 청구됩니다. 다른 사람이 같은 주소로 접속하면 그 사람은 자기 키를 따로 넣어야 합니다.

칸에 키를 넣고 연결 테스트를 바로 눌러도 됩니다. 그때 자동으로 저장됩니다.
